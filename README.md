Marketing Campaign Analytics & Financial Reporting Dashboard
🚀 Project Overview

This project is an end-to-end Marketing Campaign Analytics Dashboard built using PostgreSQL, SQL, Power BI, Excel, and Python. The goal is to transform raw digital advertising campaign data into actionable business insights through data cleaning, modeling, KPI calculations, and interactive dashboards.

The dashboard enables business users to monitor campaign performance, analyze profitability, optimize advertising spend, and evaluate marketing effectiveness across different platforms.

📌 Business Problem

Marketing teams often manage thousands of advertising campaigns across multiple platforms. Without centralized reporting, it becomes difficult to:

Measure campaign profitability
Track advertising ROI
Compare platform performance
Identify high-performing campaigns
Optimize marketing spend
Monitor business KPIs in real time

This project solves these challenges by providing an interactive financial reporting dashboard.
